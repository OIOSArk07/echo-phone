# Echo Owl Android widget

This is a home-screen-only companion for the hosted Echo phone app. It requests
no runtime permissions and has no overlay, screen capture, accessibility,
camera, microphone, location, storage, or background-service capability.

The widget is resizable. Tap the owl to open Echo. Tap **Rest** or **Wake** to
switch between the natural open-eye and closed-eye artwork.

Build with Android Studio or a compatible Android SDK/JDK installation, then
install the debug APK from `app/build/outputs/apk/debug/app-debug.apk`. After
installation, long-press an empty part of the Android home screen, choose
**Widgets**, find **Echo Owl**, and drag it onto the home screen.
